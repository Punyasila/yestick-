# Yestick - Smart Market Watchlist

Yestick is a smart, full-stack market watchlist app built to help users quickly understand what has changed in their portfolio.

## 🚀 Live Demo
[Visit Yestick](https://yestick.vercel.app)

## 🛠️ Tech Stack
- **Frontend:** Next.js 16 (App Router), React, TypeScript, Tailwind CSS
- **Backend:** Next.js API Routes, Server Components
- **State:** LocalStorage (for resilient, cross-session persistence)
- **Deployment:** Vercel

## ✨ Features
- User authentication (Sign up / Log in)
- Create and manage a smart watchlist
- Realistic, resilient market data generation
- Premium fintech-style dashboard with summary cards
- Color-coded percentage changes for market insights
- Fully responsive UI
